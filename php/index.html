Motor de Scripting: PHP 8.3 / FastCGI

Ruta DocumentRoot: C:\laragon\www\lab09

🔄 Ciclo de Vida PHP (Stateless)

  • 1. Parse: Apache recibe HTTP request y delega el script al módulo de PHP.
  • 2. Execute: Se inicializan superglobales ($_POST, $_SERVER) y ejecuta la lógica en memoria efímera.
  • 3. Output: Genera HTML y cabeceras HTTP hacia el cliente.
  • 4. Destroy: PHP libera memoria de variables tras finalizar la respuesta.

🛡️ Restricciones Técnicas del Lab

  • Prohibido el uso de register_globals.
  • Sanitización estricta con filter_input().
  • Protección contra inyección con htmlspecialchars().
  • Manejo de códigos de estado: 200 OK, 302 Redirect, 405 Method Not Allowed.
